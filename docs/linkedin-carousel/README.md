# LinkedIn document carousel

Folder ini menjadi lokasi versi ringkas untuk publikasi LinkedIn, terpisah dari deck presentasi 15 slide.

Simpan ekspor final Canva sebagai:

- HR_WLB_LinkedIn_Carousel_12_Pages.pdf — satu PDF, 12 halaman portrait 4:5.

Setiap halaman perlu dapat dipahami sendiri sekaligus melanjutkan cerita halaman sebelumnya. Gunakan judul yang jelas, satu pesan atau chart utama per halaman, nomor halaman konsisten, catatan sumber, dan caveat observasional. Hindari membagi satu chart atau kalimat ke dua halaman.

Caption LinkedIn sebaiknya menyebut sumber dataset, tautan dashboard dan repository, ringkasan temuan, batas interpretasi, serta satu pertanyaan untuk membuka diskusi.
