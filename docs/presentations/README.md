# Presentasi proyek

Folder ini menjadi lokasi dokumen presentasi versi panjang untuk HR, manajemen, dan pemangku kepentingan.

Simpan hasil akhir Canva atau PowerPoint di sini:

- HR_WLB_Presentation_15_Slides.pptx — deck presentasi 15 slide, 16:9.
- HR_WLB_Presentation_15_Slides.pdf — salinan PDF untuk dibaca atau dibagikan.

Deck mencakup konteks bisnis, metodologi, temuan WLB, perbandingan overtime, kepuasan dan attrition, dashboard, rekomendasi, batasan, serta next steps. Speaker notes menyimpan narasi presenter untuk durasi 8–12 menit.

Cantumkan atribusi sumber data pada slide Metodologi atau Data Overview:

    Sumber data: IBM HR Analytics Employee Attrition & Performance (ODbL 1.0 / DbCL 1.0), file encoded dari apoorva2796/DataSet. Cleaning dan analisis: Eriel Setiawan Dewantoro.
